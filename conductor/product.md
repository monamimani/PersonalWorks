# Initial Concept
A personal C++23 playground for developing and exploring various coding concepts.

# Product Definition
## Vision
To provide a modular, high-performance C++23 environment for rapid prototyping, engine development, and technical experimentation.

## Core Pillars
- **Experimentation:** A safe space to explore new C++ standards and idioms.
- **Engine Development:** A long-term project to build a custom game engine (`EnginePlayground`).
- **Isolation:** Isolated components (`CodeIncubator`) for refining ideas before integration.

## Target Audience
Personal use and potential open-source contributors or learners interested in modern C++ and engine architecture.

## Key Features
- **Engine Playground:** Core engine development (Gfx, Core, ApplicationCore).
- **Code Incubator:** Sandbox for new features.
- **Code Exercises:** Dedicated space for algorithm practice.
- **Onnx Inference:** Integration of machine learning models.
