# Technology Stack

## Core Language & Tooling
- **Language:** C++26
- **Build System:** CMake
- **Build Generator:** Ninja
- **Dependency Management:** vcpkg

## Libraries & Frameworks
- **Logging:** spdlog
- **Graphics/Compute API:** Vulkan
- **Development UI Framework:** ImGui (Used specifically for developer tools and debugging interfaces, not the main application UI)

## Testing & Benchmarking
- **Unit Testing (Primary):** gtest
- **Unit Testing (Secondary):** Catch2
- **Performance Benchmarking:** Google Benchmark

## Infrastructure & DevOps
- **CI/CD:** GitHub Actions
